資料助秘密碼查找器
找回「自己」忘記的密碼 · 全程本機

WiFi 密碼

顯示這台電腦「已經記住」的無線網路密碼，等同 Windows 設定裡本來就看得到的資訊。

文字抓密碼

把郵件或文件內文貼進來，自動抓出像「密碼是 XXX」「password: XXX」這類寫在文字裡的密碼。

壓縮檔密碼

回復自己忘記的 ZIP / 7z / RAR 密碼。成功的密碼會自動存入學習庫，下次優先嘗試、更快命中。

Office 密碼（Word / Excel / PPT）

回復自己忘記的 .docx / .xlsx / .pptx 開啟密碼。成功後一樣存入學習庫。

星號密碼顯示

把滑鼠移到某個軟體的密碼欄（顯示 ●●● 的那格）上，再按下方按鈕，試著還原成文字。
僅對傳統 Windows 密碼框有效；瀏覽器、UWP、Electron 等自繪欄位系統無法讀取。

郵件密碼

還原本機 Thunderbird / Outlook 已經替你記住的郵件帳號密碼。全程本機，不連線、不猜測他人信箱。

學習庫與資料庫

預設用本機學習庫（零設定）。若要多人共用、沿用資料助秘的帳號權限，可改接 MariaDB。
